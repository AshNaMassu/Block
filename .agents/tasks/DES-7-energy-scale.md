## Контекст
- Первоисточник: [docs/DESIGN-neon-alchemy.md](../../docs/DESIGN-neon-alchemy.md) §11 (шкала), §3 (композиция), §12–14 — вне рамок (DES-8/9/10/11).
- Существующее: `EnergyView` (3 слота, поп-ин fill цветом стихии), `CleansingFx` (вспышка+кольца), `FuryView` (чип с таймером), core `addEnergy` (consumed/overflow), `PlacementResult.clearedLines` (element+cells — координаты молний), `DetonationResult.element/region`.
- Порядок энергии core: `[detonation.element] + gainedElements` (строки, затем столбцы) — молнии должны лететь в этом же порядке.
- DESIGN §3: шкала НАД полем («игрок должен видеть, как награда летит из поля в шкалу»). Сейчас — ПОД полем (ENERGY_Y=1340 при поле 300..1260). Перенос — UI-полировка, в рамках таска.

## Решение (автономный выбор)
1. **Перенос шкалы над поле** (`layout.ts`): ENERGY_Y 1340→350, BOARD_TOP 300→420,
   FURY_Y 1230→1300 (чип на нижней кромке поля, как раньше висел над старой шкалой).
   BONUS_Y/HAND не трогаем (не пересекаются: поле кончается 1380, бонусный ряд 1400..1580).
2. **EnergyBoltFx** (`fx/EnergyBoltFx.ts`): генерируемая текстура-молния (зигзаг, белая, tint стихии),
   полёт из точки источника в слот со стагером ~120 мс; по прилёту — вспышка на слоте.
   Переполненные молнии летят в зону пипсов над шкалой.
3. **EnergyView**: бледная молния-иконка в пустом слоте (§11 «внутри бледная молния»);
   `showOverflow(overflow, furyMult)` — золотые пипсы «+N» над шкалой + подпись «Fury ×M»,
   скрываются после церемонии.
4. **GameScene.afterMove**: собрать gains (детонация + стихийные линии, центры клеток),
   после lineClearFx → молнии → (cleansing: пипсы+подпись → CleansingFx → refreshEnergy
   | иначе refreshEnergy по прилёту молний).
