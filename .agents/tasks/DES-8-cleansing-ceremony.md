# DES-8: Церемония Очищения — вспышка, схлопывание слотов, награды летят в руку/счётчик

## Статус
✅ ЗАВЕРШЁН — коммит d88aa89; просмотр автором — в общем финале волны.

## Контекст
- Первоисточник: [docs/DESIGN-neon-alchemy.md](../../docs/DESIGN-neon-alchemy.md) §11 «Момент Очищения» (DES-8 = пункты 1–5; Fury-таймер после — DES-9).
- Сценарий по DESIGN: экран слегка темнеет → шкала вспыхивает белым/золотым → три слота
  схлопываются в центр → крупная надпись «Очищение» → звезда летит в счётчик, радужные
  фигуры падают в бонусные слоты. Длительность 1–1.5 с.
- Существующее: CleansingFx (вспышка+кольца+тряска, FxPool), EnergyView (слоты, drain,
  showOverflow), ToastManager (тост награды уже есть), HAND_SLOTS[3..5] (бонусные слоты),
  HUD_STARS_X/Y (счётчик звёзд). Игра: feedback автора 30.10 — «не хватает праздника».

## Решение (автономный выбор)
- CleansingFx.play расширяется опциональными колбэками и фазами (подпись не менять — назад
  совместимо): dim-оверлей (yoy, 0.45) уже есть вспышкой; добавить:
  1) колбэк onPeak в момент пика вспышки → EnergyView.collapseToCenter() (слоты съезжаются
     в центр шкалы и гаснут);
  2) крупная надпись «ОЧИЩЕНИЕ» в центре поля (золото, Back.Out scale-in, затем fade);
  3) полёт звезды (Text ★, золото) из центра шкалы в HUD-счётчик + радужные чипы
     (TEX_RAINBOW) в бонусные слоты руки со стагером (декор: рука уже обновлена engine).
- EnergyView.collapseToCenter(onDone): tween fills к слоту 1 (центр) + scale→0 + fade.
- GameScene: в ветке cleansing вызвать расширенную церемонию (звезда/радуга из
  result.starsGained / result.rainbowAdded), refreshEnergy после collapse.
