## Проект в двух словах

**Elemental Blast** — гибрид block-puzzle «поставил фигуру — собрал линию стихии» под **Яндекс.Игры**: 8×8 сетка, рука из фигур (включая rainbow и 4 детонатора стихий с мерджем), линии стихий копят Energy, 3/3 → Очищение, комбо дают спецфигуры, Fury-режим с таймером.

- **Стек:** TypeScript 5.x (strict) + Phaser 3 + Vite + Vitest. ESLint + Prettier. RNG — детерминированный (mulberry32).
- **Железное правило:** `src/core` не зависит от Phaser (ESLint `no-restricted-imports` ловит нарушение). Весь игровой расчёт — в core, Phaser — только view/ввод/FX.
- **Код:** в `game/` (не в корне!) — `game/index.html`, `game/src/`, `game/package.json`. Все npm-команды — из `game/`.
- **Локализация:** `src/i18n`.

## Как запустить и проверять

```bash
cd D:\Projects\Unity\Block\game
npm run check   # lint → format:check → tsc --noEmit → vitest run (полная проверка)
npm test        # только юнит-тесты core (~190)
npm run build   # tsc + vite build → dist/
npm run dev     # ТОЛЬКО с разрешения пользователя (RULES п.12)
```

Сборка в `game/dist/` — ZIP оттуда уходит на Яндекс.Игры (T-059).

## URL-параметры отладки

- `?debug=1` — дебаг-хаб (DebugHubScene): песочница, кисть (тап кладёт стихию, ластик), 15 пресет-сцен (детонаторы, комбо 2–5, pure, радужная, мердж), сводка `DEBUG: ...` под HUD. В прод не попадает: кнопка DEBUG обёрнута в `import.meta.env.DEV`.

## Главные грабли (прочитать перед правками)

1. **docs/PROGRESS.md отстаёт от кода.** T-040..T-044 там не отмечены, но сделаны (коммиты e07e345, cfe08a6); часть подзадач тоже устарела. Верить коду и `git log`, не чекбоксам. Прогресс-док синхронизировать только по отдельной просьбе.
2. **ELEMENT_COUNT=4** в `config/elements.ts` — осознанная правка баланса автора (при 1–2 стихийные линии не собирались). Не «чинить» обратно.
3. **DRAG_OFFSET_Y:** drag-копия фигуры рендерится на 140 design-px выше пальца. Для CUA-тестов drag целиться на ~70 css-px ниже центра клетки (viewport 540). Это не баг.
4. **Стек веток:** `main` → `feature/elemental-detonators` → `feature/crystal-visual` → `feature/debug-mode`. До мержа цепочкой правки в «кристаллы» или «детонаторы» приведут к конфликтам при слиянии.
5. **Core чист от Phaser** — при добавлении расчётной логики в `core/` не тянуть импорты Phaser; тесты core гоняются в Vitest без канваса.
6. **Тесты — 190/190, tsc чист** на текущей голове. После правок core — `npm test`; после правок view — `npx tsc --noEmit` минимум.
7. **Пресет «Пожар — угол»** требует пустой клетки постановки (детонатор ставится на пустую клетку рядом с целью) — не менять раскладку пресета без проверки в игре.
8. **DetonationFx/FxPool** — переиспользование через пул; при добавлении новых FX следовать паттерну `LineClearFx`.
