# DESIGN — «Неоновая алхимия» (тёмная тема Elemental Blast)

> Первоисточник UX/UI-концепта для волн DES-1..DES-15 (см. .agents/QUEUE.md).
> Принято автором 2026-10-29: тема — тёмная (замена «Кристаллов»), арт — генерация по пачкам §29, реализация волнами.
> Числа в тексте (+2500, ×2.0, +6000...) — иллюстративные: в реализации сверять с config/balance.ts.

Ок, задача понятна. Тут главное не «сделать красиво», а сделать так, чтобы игрок **без текста понимал причинно-следственную связь**:

> стихийная линия → энергия → очищение → радужные фигуры → комбо → спецфигуры → детонации → снова энергия.

Сейчас система сложная, поэтому визуал должен быть не просто стилем, а **языком подсказок**. Ниже — концепт UX/UI-дизайна, который можно брать как основу для арт-промптов.

---

# 1. Главная дизайн-идея

## Стиль: «Неоновая алхимия / стеклянные стихии»

Я бы уходил от слишком детского пазла и от перегруженного фэнтези. Лучше всего подойдёт стиль:

**тёмный фон + стеклянные/светящиеся стихийные элементы + золотые бонусные акценты + чистый казуальный UI.**

Ассоциации:
- дорогие стеклянные камни;
- алхимический реактор;
- стихийные кристаллы;
- мягкое неоновое свечение;
- простые округлые формы;
- минимум лишних деталей.

Главный принцип:

> Обычные механики — спокойные.  
> Бонусные механики — яркие, золотые, светящиеся.  
> Опасность/ошибка — красная.  
> Подтверждение действия — белое/светло-голубое.  
> Радуга — единственный объект с переливающимся градиентом.

---

# 2. Основные правила визуальной иерархии

Игрок должен за 3 секунды понимать:

1. Где поле.
2. Где фигуры.
3. Что можно поставить.
4. Что сейчас очистится.
5. Где копится энергия.
6. Когда будет награда.

Поэтому иерархия такая:

## Уровень 1 — игровое поле
Самое крупное, контрастное, в центре экрана.

## Уровень 2 — рука с фигурами
Внизу, хорошо читается, фигуры крупные.

## Уровень 3 — шкала Очищения / Энергии
Над полем, компактно, но заметно.

## Уровень 4 — счёт, Fury, звёзды
Сверху, не мешают, но видны.

---

# 3. Общая композиция экрана

Примерная схема портретного экрана:

```text
┌────────────────────────────────┐
│  Счёт        Fury/бафф     ★   │
│                                │
│   [Шкала Очищения: ⚡⚡⚡]      │
│   [переполнение: +1 +2]       │
│                                │
│                                │
│         ИГРОВОЕ ПОЛЕ 8×8       │
│                                │
│                                │
│                                │
│   [бонусные золотые слоты]     │
│   [обычные 3 слота фигур]      │
└────────────────────────────────┘
```

Важно: **шкалу энергии лучше размещать над полем**, а не сбоку. Игрок должен видеть, как награда летит из поля в шкалу.

# 4. Цветовая система

## Базовый фон

| Элемент | Цвет | Зачем |
|---|---|---|
| Фон приложения | `#060A13` | Глубокий тёмно-синий, почти чёрный |
| Игровой фон | Радиальный градиент `#0C1526 → #060A13` | Создаёт глубину, но не мешает полю |
| Панели | `#101A2E` | UI-плашки, слоты, подсказки |
| Бордюры панелей | `#26385A` | Лёгкая обводка, без агрессивного контраста |
| Текст основной | `#F4F7FF` | Почти белый, холодный |
| Текст вторичный | `#9FB0D0` | Подписи, подсказки |
| Неактивный текст | `#5D6E8F` | Затемнённые состояния |

---

## Золото для бонусов

Всё, что связано с бонусами, наградами, очищением, радужными фигурами, должно быть в золотой/янтарной гамме.

| Роль | Цвет |
|---|---|
| Основной золотой | `#FFC24D` |
| Тёплый янтарный | `#FFA726` |
| Тёмное золото | `#D98F1F` |
| Светлое золото | `#FFE3A3` |

Золотыми должны быть:
- бонусные слоты;
- радужная фигура частично;
- очищение;
- награда за комбо;
- звёзды;
- Fury-таймер.

---

## Служебные цвета

| Состояние | Цвет | Использование |
|---|---|---|
| Энергия | `#FFE45C` | Молнии, заряды, шкала |
| Ярость / Fury | Градиент `#FFC24D → #FF4DA6` | Таймер, множитель, рамка поля |
| Ошибка / нельзя поставить | `#FF4D6D` | Красная подсветка, тряска |
| Успех / подтверждение | `#7CF2C4` или белый | Лучше использовать белый/светло-голубой, чтобы не путать с землёй |
| Выделение | Белый `#FFFFFF` | Выбранная фигура, слияние |

Я бы осторожно использовал зелёный для «успеха», потому что уже есть стихия земли. Лучше:

- можно ставить: белая/светло-голубая подсветка;
- нельзя ставить: красная;
- награда: золотая.

---

# 5. Цвета и визуальный код стихий

Каждая стихия должна иметь:
1. Свой цвет.
2. Свой значок.
3. Свой тип свечения.
4. Свой звук/частицы.
5. Свою форму-подсказку для дальтоников.

---

## 🔥 Огонь

**Основной цвет:** `#FF6A3D`  
**Тёмный цвет:** `#C2401C`  
**Светлый цвет:** `#FFD7C2`  
**Свечение:** `#FF8C5A`

Визуал:
- тёплый оранжевый кристалл;
- внутри мягкое пламя;

- при очистке — волна;

## 🌿 Земля

**Основной цвет:** `#57D06C`  
**Тёмный цвет:** `#2E9E4F`  
**Светлый цвет:** `#D2F8D2`  
**Свечение:** `#7CE68D`

Визуал:
- зелёный кристалл с листом;
- чуть более плотный, «каменно-природный» вид;
- мягкие органические линии.

Дополнительный символ:
- лист или росток.

Эффекты:
- при очистке — зелёная волна с листьями;
- звук: мягкий каменный/природный удар;
- частицы: листья, светящаяся пыльца.

---

## 💨 Воздух

Тут важно не сделать его похожим на воду. Поэтому лучше не чисто-голубой, а **лавандово-воздушный**.

**Основной цвет:** `#BFA7FF`  
**Тёмный цвет:** `#7C5CE0`  
**Светлый цвет:** `#F1EAFF`  
**Свечение:** `#D7C8FF`

Визуал:
- светло-фиолетовый полупрозрачный кристалл;
- внутри завиток, вихрь, поток воздуха;
- ощущение лёгкости.

Дополнительный символ:
- спираль или три дуги ветра.

Эффекты:
- при очистке — воздушный вихрь;
- звук: лёгкий свист/чайм;
- частицы: светлые потоки, завихрения.

---

## 🌈 Радужная фигура

Радуга должна быть **единственным объектом**, который использует полноценный анимированный спектр.

Цвета радуги:
- `#FF6E7E`
- `#FFC24D`
- `#7CFFB2`
- `#56D2FF`
- `#C7A6FF`

Визуал:
- стеклянный призматический кристалл;
- медленно переливается;
- вокруг лёгкое спектральное свечение;
- не должна выглядеть как обычная стихия.

Важно:
- радуга не должна быть слишком пёстрой в покое;
- она должна выглядеть как «дикий кристалл», который подстраивается под стихию.

Когда радужная фигура стоит рядом с 7 огнями, она должна получить:
- огненное кольцо;
- маленький значок огня;
- подсказку: «станет 🔥».

---

# 6. Игровое поле

Поле — главный объект. Оно должно быть спокойным, но живым.

## Фон поля
- тёмная панель: `#0A1220`;
- лёгкая синяя рамка: `#223252`;
- снаружи мягкое свечение, особенно во время Fury.

## Пустая клетка
- фон: `#111C31`;
- тонкий бордюр: `#24385C`;
- лёгкая внутренняя тень;
- скругление: 10–14 px в зависимости от размера.

Пустые клетки не должны быть слишком заметными. Они просто сетка.

---

## Заполненная клетка стихии

Каждая клетка — это не просто цветной квадрат, а «стеклянный элемент»:

- основной цвет стихии;
- светлый блик сверху;
- тёмный низ;
- лёгкое внешнее свечение;
- маленький символ стихии в углу или полупрозрачный знак внутри.

Но не перегружать. В обычной клетке символ должен быть очень деликатным, примерно 8–12% opacity.

Когда клетка становится частью потенциальной стихийной линии, символ можно делать ярче.

---

## Подсветка потенциальных линий

Это критически важно для понимания бонусной системы.

Если в ряду/столбце уже есть 6–7 клеток одной стихии, нужно показывать слабую подсказку:

### 6 клеток одной стихии
- между ними появляется еле заметная светящаяся нить;
- цвет нити — цвет стихии;
- прозрачность низкая.

### 7 клеток одной стихии
- нить становится ярче;
- край ряда начинает мягко пульсировать;
- на краю ряда можно показать маленький призрак награды: `+2500` или значок `+1⚡`.

### Если в руке есть радужная фигура
- такие неполные стихийные ряды подсвечиваются радужной обводкой;
- это сразу объясняет: «радуга сюда подходит».

---

# 7. Перетаскивание фигур

Это самый важный момент в UX.

Когда игрок берёт фигуру:

1. Фигура немного увеличивается.
2. Поднимается над пальцем, чтобы палец не закрывал её.
3. Под ней появляется тень.
4. Поле слегка затемняет всё, кроме целевой области.
5. Клетки, куда можно поставить, подсвечиваются.

---

## Обычная фигура

При наведении:
- клетки под фигурой подсвечиваются белым/светло-голубым полупрозрачным слоем;
- если ставить нельзя — красная подсветка;
- если можно — мягкая светлая подсветка.

Если фигура завершает обычную линию:
- линия подсвечивается белым контуром;
- рядом появляется небольшой призрак: `+1000`.

Если фигура завершает стихийную линию:
- линия подсвечивается цветом стихии;
- появляется более крупный призрак: `+2500` и `+1⚡`;
- на конце линии можно показать иконку стихии.

Если фигура делает 2+ стихийные линии:
- над полем появляется бейдж: **Комбо ×2**;
- рядом можно показать силуэт награды.

Это очень важно: игрок заранее видит, что получит комбо.

---

## Радужная фигура

При перетаскивании радуги:
- она переливается;
- если рядом есть 7 клеток одной стихии, радуга «подхватывает» эту стихию;
- вокруг клетки появляется цветное кольцо;
- показывается подсказка: «станет 🔥», «станет 💧» и т.д.

Если есть несколько возможных линий, нужно подсвечивать лучший вариант:
- сначала стихийную линию;
- если её нет — обычную линию.

---

# 8. Рука с фигурами

Рука должна быть разделена на две зоны:

## Обычные слоты
- 3 крупных слота;
- нейтральная тёмная рамка;
- цвет обводки: `#3A4A6B`;
- фон: `#101A2E`;
- пустой слот: чуть более тёмный, с лёгким пунктиром или силуэтом.

Обычные фигуры должны выглядеть как игровые элементы, но не как бонус.

---

## Бонусные золотые слоты
- 3 слота меньше или чуть выше над обычными;
- золотая рамка;
- фон: тёмно-золотистый, но не кричащий;
- лёгкое сияние по углам.

В них размещаются:
- радужные фигуры;
- спецфигуры-детонаторы;
- другие бонусные объекты.

Важно: бонусные слоты должны быть видны всегда. Если места мало, лучше сделать их компактнее, но не прятать.

Пример расположения:

```text
[ bonus ][ bonus ][ bonus ]
[ normal ][ normal ][ normal ]
```

Или на широком экране:

```text
[ normal ][ normal ][ normal ]  |  [ bonus ][ bonus ][ bonus ]
```

Но для телефона лучше два ряда: сверху бонусы, снизу обычные фигуры.

---

# 9. Внешний вид обычных фигур

Обычная фигура — это мини-версия поля. Каждая её клетка окрашена в стихию.

Требования:
- клетки фигуры должны быть чуть крупнее, чем клетки поля в пересчёте на визуальный вес;
- между клетками фигуры должна быть тонкая связка;
- фигура должна читаться как единый объект.

Пример:
- фигура из 3 клеток — это не три отдельных квадрата, а одна плашка с тремя стихийными ячейками.

---

# 10. Внешний вид спецфигур

Спецфигуры нужно визуально отделить от обычных.

Они должны выглядеть не как «просто фигуры», а как **катализаторы**.

Общие признаки спецфигуры:
- отдельный корпус/ядро;
- иконка действия;
- цвет стихии;
- лёгкая пульсация;
- маленький бейдж эффекта;
- золотая или стихийная рамка.

Не нужно делать их слишком сложными. Игрок должен сразу видеть: «это штука, которая взрывается/чистит/красит».

---

## 🔥 Пожар — 1×1

Форма:
- круглый или квадратный огненный кристалл;
- внутри ядро лавы;
- трещины с огнём;
- оранжево-красное свечение.

Бейдж:
- иконка взрыва или 3×3 сетка.

При перетаскивании:
- вокруг клетки показывается область 3×3;
- область полупрозрачная, огненная;
- занятые клетки в области подсвечиваются как «будут очищены»;
- пустые клетки подсвечиваются как «станут огнём».

При установке:
- вспышка;
- огонь заполняет 3×3;
- летит `+1⚡` в шкалу.

---

## 💧 Прилив — 1×2

Форма:
- капсула из двух водных ячеек;
- внутри волна;
- лёгкое течение.

Бейдж:
- стрелка вдоль линии;
- иконка волны.

Главная UX-проблема: ориентация.

Нужен явный переключатель:
- либо кнопка `↻` рядом с фигурой;
- либо при выборе фигуры появляются два варианта: «ряд» и «столбец»;
- либо во время перетаскивания рядом с фигурой плавает маленькая кнопка смены ориентации.

При перетаскивании:
- если горизонтально: подсвечивается весь ряд;
- если вертикально: подсвечивается весь столбец;
- подсветка синяя, волновая;
- рядом подсказка: «Смоет ряд» или «Смоет столбец».

При установке:
- волна проходит по линии;
- линия становится водой;
- затем схлопывается как стихийная линия.

---

## 🌀 Вихрь — 1×1

Форма:
- фиолетово-воздушный кристалл;
- внутри спираль;
- вокруг лёгкие потоки воздуха.

Бейдж:
- спираль;
- можно показывать текущую доминирующую стихию, если это возможно.

В покое:
- лучше показывать просто спираль.

При перетаскивании:
- все клетки самой частой стихии на поле подсвечиваются;
- над ними появляются маленькие спиральки;
- сверху можно показать счётчик: например, `💧 ×12`.

При установке:
- все отмеченные клетки затягиваются в центр;
- вихрь делает глобальную чистку;
- летит `+1⚡` стихии самой фигуры.

---

## 🌿 Родник — 2×2

Форма:
- зелёный кристалл/цветок;
- 2×2 ячейки;
- мягкое природное свечение.

Бейдж:
- 4×4 область;
- лист/росток.

При перетаскивании:
- показывается область 4×4;
- внутри показывается доминирующая стихия области;
- если область станет, например, огненной, показываем: `🔥 зона`;
- пустые клетки подсвечиваются как заполняемые.

При установке:
- область мягко перекрашивается;
- не взрыв, а «волна роста»;
- это должно выглядеть как созидание, а не разрушение.

---

# 11. Визуал шкалы Энергии / Очищения

Это один из самых важных элементов. Нужно сделать так, чтобы игрок сразу понял:

> Сюда падают молнии → когда 3 штуки → происходит Очищение.

## Форма шкалы

Лучше всего:
- горизонтальная плашка над полем;
- три круглых/шестигранных слота;
- каждый слот похож на мини-реактор.

В пустом состоянии:
- тёмный слот;
- слабый контур;
- внутри бледная молния.

При получении `+1⚡`:
- из поля вылетает цветная молния;
- цвет молнии = стихия источника;
- молния попадает в слот;
- слот заполняется.

---

## Заполнение шкалы

Каждый заряд должен быть цветным:
- огонь — оранжевая молния;
- вода — голубая;
- земля — зелёная;
- воздух — фиолетовая.

Это помогает понять, откуда приходит энергия, но не заставляет делать четыре отдельных шкалы.

Важное решение:

> Я бы делал одну общую шкалу Очищения, но заряды в ней красил цветом стихии.

Если по механике энергия всё-таки отдельная по стихиям, тогда лучше сделать четыре компактных кольца по углам поля. Но для UX проще и чище один общий реактор.

---

## Переполнение

Если при заполнении пришло больше трёх молний, нужно показать переполнение.

Визуал:
- три основных слота заполнены;
- сверху появляются маленькие золотые искры/пипсы: `+1`, `+2`;
- рядом показывается будущий множитель: `×2.0`, `×3.5`, `×5.0`.

Пример подписи:

```text
Переполнение +2 → Fury ×3.0
```

Это объясняет, зачем ловить большой комбо-момент.

---

## Момент Очищения

Когда шкала заполняется:

1. Экран слегка затемняется.
2. Шкала вспыхивает белым/золотым.
3. Три слота схлопываются в центр.
4. Появляется крупная надпись: **Очищение**.
5. Показываются награды:
   - `+6000+`;
   - `+1★`;
   - `+3 🌈 фигуры`.

Затем:
- звёздочка летит в верхний счётчик;
- три радужные фигуры падают в бонусные слоты;
- появляется Fury-таймер.

Это должен быть маленький праздник, но не длинный. 1–1.5 секунды достаточно.

---

# 12. Визуал Fury

Fury должен быть заметным, но не мешать игре.

Лучший вариант:
- шкала Очищения превращается в компактный таймер;
- вокруг поля появляется мягкая золотисто-розовая рамка;
- возле счёта висит бейдж множителя.

Пример:

```text
Fury ×3.2   00:41
```

## Цвет Fury
Градиент:
- `#FFC24D`
- `#FF7A4D`
- `#FF4DA6`

## Эффекты во время Fury
- фон становится чуть теплее;
- рамки поля светятся;
- все начисления очков получают золотой стиль;
- возле числа появляется маленький значок `×`;
- таймер убывает по кругу или полосой.

Не нужно делать полноэкранную вспышку на весь матч. Это будет раздражать.

Последние 5 секунд:
- таймер начинает пульсировать;
- рамка чуть гаснет;
- звук мягко затухает.

---

# 13. Визуал комбо

Комбо должно быть понятным ещё до того, как игрок поставил фигуру.

## Во время перетаскивания

Если фигура замыкает 2+ стихийные линии:
- линии подсвечиваются своими стихийными цветами;
- над полем появляется бейдж: `Комбо ×2`;
- рядом показывается награда: силуэт спецфигуры.

Если 3 линии:
- `Комбо ×3`;
- награда — Прилив.

Если 4:
- `Комбо ×4`;
- награда — Вихрь.

Если 5–6:
- `Комбо ×5+`;
- награда — Родник.

---

## После установки

1. Линии очищаются не одновременно, а с небольшой очередью: 80–120 мс между ними.
2. Каждая линия даёт свой стихийный эффект.
3. В центре появляется крупный бейдж:

```text
КОМБО ×3
```

4. Из места очистки вылетает карточка спецфигуры.
5. Она летит в бонусный слот.

Это важно: награда должна физически прилететь в руку. Игрок должен видеть, откуда она взялась.

---

# 14. Визуал слияния спецфигур

Слияние должно быть очевидным.

Когда в руке есть две одинаковые спецфигуры:

- на обеих появляется маленький золотой значок связи;
- можно показать тонкую пульсирующую линию между ними;
- при тапе по первой:
  - белая пульсирующая рамка;
  - вторая фигура начинает мягко пульсировать;
  - между ними появляется стрелка/дуга.

При тапе по второй:
- фигуры стягиваются;
- вспышка;
- появляется новая фигура уровнем выше;
- сверху можно показать цепочку:

```text
🔥 → 💧 → 🌀 → 🌿 → 🌈
```

Если игрок тапнул по разной паре:
- лёгкая тряска;
- подсказка: «Нужна такая же фигура».

---

# 15. Подсказки и обучение

Главная ошибка — пытаться объяснить всё сразу. Обучение должно быть контекстным.

## Контекстные подсказки

### Первый раз, когда игрок собирает стихийную линию
Показать короткую плашку:

```text
Стихийная линия!
+2500 и +1⚡
```

### Первый раз, когда шкала заполнилась
Показать:

```text
Очищение!
Ты получаешь 3 радужные фигуры и запускаешь Fury.
```

### Первый раз, когда игрок получил спецфигуру
Показать:

```text
Катализатор!
Перетащи его на поле — он сработает при установке.
```

### Первый раз, когда можно слить две фигуры
Показать:

```text
Можно объединить!
Тапни по двум одинаковым катализаторам.
```

---

# 16. Постоянные микроподсказки

В интерфейсе должны быть короткие подписи, но не длинные.

## Шкала энергии

Когда 0/3:
```text
Заполни 3 ⚡ для Очищения
```

Когда 2/3:
```text
Ещё 1⚡ до Очищения
```

Когда переполнение:
```text
Лишние ⚡ усилят Fury
```

---

## Спецфигуры

Короткие подписи должны быть глагольными:

### Пожар
```text
Взрыв 3×3, заполняет огнём
```

### Прилив
```text
Смывает ряд или столбец
```

### Вихрь
```text
Убирает самую частую стихию
```

### Родник
```text
Красит область 4×4 в одну стихию
```

### Радуга
```text
Становится любой стихией
```

---

# 17. Ошибки и невозможность хода

Когда фигуру нельзя поставить:
- фигура слегка трясётся;
- целевая область красная;
- звук мягкий, не раздражающий;
- без крупного текста.

Если ни одна фигура не помещается:
- фигуры в руке становятся чуть серее;
- на них появляется маленький красный индикатор;
- поле получает слабую красную виньетку;
- появляется экран конца игры.

---

# 18. Экран Game Over

Не надо делать его слишком агрессивным. Игрок и так проиграл.

Лучше:
- тёмный оверлей;
- поле размыто/затемнено;
- крупный счёт;
- лучший результат;
- статистика;
- кнопка «Ещё раз».

Статистика:
- стихийные линии;
- комбо;
- очищения;
- использовано спецфигур;
- максимальный множитель.

Полезно дать совет:

```text
Совет: объединяй одинаковые катализаторы, чтобы получить более сильный эффект.
```

или:

```text
Совет: радужная фигура может завершить стихийную линию.
```

---

# 19. Типографика

Нужен шрифт с поддержкой кириллицы, округлый, но технологичный.

Хорошие варианты:
- **Manrope**;
- **Golos Text**;
- **Rubik**;
- **Onest**;
- **Montserrat** — если нужен более жирный и геометричный стиль.

## Размеры
- Счёт: 28–36 pt, ExtraBold.
- Множитель / Fury: 16–20 pt, Bold.
- Подписи: 12–14 pt.
- Кнопки: 16–18 pt.

Важно:
- цифры должны быть табличными, чтобы счёт не прыгал;
- текст короткий;
- никаких длинных объяснений во время боя.

---

# 20. Форма и стилизация

## Общие формы
- всё скруглённое;
- радиусы крупные, но не чрезмерные;
- панели — мягкие прямоугольники;
- клетки поля — квадраты с радиусом 10–14 px;
- кнопки — крупные, пальцедружелюбные.

## Глубина
Не использовать тяжёлые тени. Лучше:
- лёгкие внутренние тени;
- мягкие свечения;
- полупрозрачные панели;
- деликатный блюр на фоне.

## Стиль
Не:
- не реализм;
- не плоский детский стиль;
- не перегруженный фэнтези-орнамент;
- не казино-золото везде.

Да:
- тёмный премиальный казуал;
- стеклянные элементы;
- мягкий неон;
- золото только для бонусов.

---

# 21. Анимации

Анимация должна объяснять механику.

## Ключевые анимации

### Установка фигуры
- лёгкий отскок;
- мягкое свечение;
- длительность 120–180 мс.

### Очистка обычной линии
- белая вспышка;
- клетки растворяются;
- летит `+1000`.

### Очистка стихийной линии
- стихийный луч;
- иконка стихии;
- летит `+2500`;
- отдельная молния летит в шкалу энергии.

### Комбо
- линии очищаются по очереди;
- бейдж комбо увеличивается;
- спецфигура летит в бонусный слот.

### Очищение
- шкала вспыхивает;
- заряды схлопываются;
- радужные фигуры падают в руку;
- звезда летит в счётчик.

### Fury
- появляется таймер;
- рамка поля загорается;
- все очки получают золотой стиль.

---

# 22. Цветовые и световые акценты

Нужно жёстко закрепить значения:

| Что означает | Цвет |
|---|---|
| Обычная линия | Белый / светло-голубой |
| Стихийная линия | Цвет стихии |
| Бонус/награда | Золотой |
| Энергия | Жёлтая молния с оттенком стихии |
| Радуга | Спектральный градиент |
| Ошибка | Красный |
| Выделение/слияние | Белый |
| Fury | Золотисто-розовый |

Это нужно соблюдать очень строго. Если золото начнёт использоваться и для обычных элементов, система снова станет непонятной.

---

# 23. Подсветки во время планирования хода

Это самая важная часть для понимания бонусов.

## Когда игрок берёт обычную фигуру
Подсвечивать:
- куда можно поставить;
- какие линии очистятся;
- будет ли стихийная линия;
- будет ли комбо.

## Когда игрок берёт радугу
Подсвечивать:
- все ряды/столбцы, где радуга может завершить стихийную линию;
- лучший вариант делать более ярким.

## Когда игрок берёт спецфигуру
Показывать:
- область действия;
- тип эффекта;
- сколько клеток будет затронуто;
- если эффект создаёт стихийную линию — показывать это.

---

# 24. Спецфигуры: визуальные различия

Чтобы игрок не путал их, нужна разная форма и цвет.

| Фигура | Форма | Цвет | Иконка | Эффект |
|---|---|---|---|---|
| Пожар | круг/квадрат с ядром | оранжевый/красный | взрыв, огонь | 3×3 |
| Прилив | капсула 1×2 | синий | волна | ряд/столбец |
| Вихрь | ромб/круг со спиралью | фиолетовый | спираль | самая частая стихия |
| Родник | 2×2 лист/цветок | зелёный | росток | зона 4×4 |
| Радуга | призма/кристалл | спектр | звезда/перелив | любая стихия |

---

# 25. Доступность

Очень важно, потому что много цветовых состояний.

## Дальтонизм
Каждая стихия должна иметь не только цвет, но и символ:
- огонь — пламя;
- вода — капля;
- земля — лист;
- воздух — спираль.

В настройках можно включить более явные иконки на клетках.

## Контраст
- текст на тёмном фоне должен быть контрастным;
- не использовать только цвет для обозначения состояния;
- ошибки дублировать формой/иконкой.

## Управление
- фигуру можно ставить не только перетаскиванием, но и тап-выбором + тап по клетке;
- для Прилива нужна отдельная кнопка поворота;
- для слияния — понятный тап по двум фигурам.

## Снижение эффектов
Нужны опции:
- уменьшить вспышки;
- отключить тряску;
- уменьшить частицы;
- упростить фон.

---

# 26. Звук и вибро

Звук должен помогать понимать систему.

## Звуки
- обычная установка: мягкий `tap`;
- стихийные линии: разные тембры;
- энергия: восходящий электрический звук;
- очищение: крупный аккорд;
- Fury: фоновый слой становится интенсивнее;
- комбо: удар/акцент;
- слияние: магический `whoosh`.

## Вибро
- установка: лёгкая;
- очистка: средняя;
- стихийная линия: двойной мягкий удар;
- комбо: серия;
- очищение: длинная волна;
- ошибка: короткий резкий сигнал.

---

# 27. Чего нельзя делать

Чтобы не ухудшить понимание:

1. Не делать обычный фон слишком ярким.
2. Не использовать золото для обычных фигур.
3. Не делать четыре большие шкалы энергии, если можно сделать одну.
4. Не показывать длинные тексты во время игры.
5. Не делать радужную фигуру слишком пёстрой в неактивном состоянии.
6. Не смешивать красный цвет с огнём там, где он означает ошибку.
7. Не прятать бонусные слоты.
8. Не делать спецфигуры визуально одинаковыми.
9. Не показывать награду без источника — игрок должен видеть, откуда она прилетела.
10. Не делать Fury-эффекты слишком навязчивыми.

# 29. Что дальше

Дальше можно разбить этот концепт на промпты для генерации арта. Я бы делал их по таким пачкам:

1. **Общий стиль / мудборд**  
   Ключевой визуал игры, настроение, палитра.

2. **Фон игрового поля**  
   Тёмный алхимический фон, мягкое свечение, без деталей.

3. **Игровое поле и клетки**  
   Пустые клетки, заполненные стихии, состояния подсветки.

4. **Стихийные кристаллы**  
   Огонь, вода, земля, воздух в едином стиле.

5. **Радужная фигура**  
   Призматический кристалл, универсальный дикий элемент.

6. **Спецфигуры**  
   Пожар, Прилив, Вихрь, Родник.

7. **UI-панели и шкала энергии**  
   Верхняя панель, слоты молний, переполнение, Очищение.

8. **Бонусные слоты и рука**  
   Обычные и золотые слоты, пустые состояния.
