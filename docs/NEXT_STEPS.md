# Ближайшие задачи — дебаг-режим и далее

Актуально после коммита `wip: дебаг-режим` на ветке `feature/debug-mode`.
Стек веток: `main` → `feature/elemental-detonators` → `feature/crystal-visual` → `feature/debug-mode`.

## 1. Баг: залипший preview-оверлей после drag&drop

**Симптом:** после постановки фигуры на поле остаётся один зелёный
preview-оверлей (TEX_PREVIEW_OK) на клетке рядом с местом постановки.
Воспроизводится: dev-сервер → DEBUG → пресет «🔥 Пожар — центр» → перетащить
Пожар из бонусного слота на (3,3).

**Куда смотреть:** `game/src/game/input/DragController.ts` — порядок
`handleUp` (place → onPlaced → cleanup → clearPreview) и `handleMove`
(последний `showPreview` после финального `clearPreview`?). Возможно,
CUA/тач-ввод присылает pointermove после pointerup, либо preview рисуется
между `onPlaced` и `cleanup`. Проверить, что `cleanup()` всегда последний
и `clearPreview()` вызывается после любого `showPreview`.

## 2. Прогнать остальные пресеты в браузере

Через DEBUG-хаб (`npm run dev` → 🐞 DEBUG):
- 💧 Прилив — строка (постановка в (6,4), ориентация row) / — столбец ((2,6), column)
- 🌀 Вихрь и Вихрь — ничья (тай-брейк по меньшему ElementId)
- 🌿 Родник (постановка в (3,3), перекраска 4×4, включая multi)
- ⭐ Комбо 2/3/4/5 (постановка обычных фигур в указанные клетки из описания пресета)
- ✨ Чистое Очищение (постановка в (0,0))
- 🌈 Радужная в линии (в (7,6))
- 🔀 Мердж в руке (тап-тап по двум Пожарам → Прилив)

Сводка каждого хода видна строкой `DEBUG: ...` под HUD.

## 3. Проверить панель и кисть

- 🐞 в GameScene: спавн тройки фиксированной стихией («РУКА ЗАНОВО» после выбора).
- Кисть: тап по клетке кладёт стихию, 🧽 — ластик; drag при активной кисти
  не должен начинаться при тапе по полю.
- Выдача радужной/детонаторов, +1⚡, очистка поля.

## 4. Опционально

- Юнит-тесты на debug-API движка (debugGiveSpecial/debugRefillHand/фильтр спавна).
- Прилив в руке: перерисовка drag-копии при смене ориентации жестом —
  проверить на живом таче (renderPiece вызывается каждый move — дороговато,
  можно перерисовывать только при смене ориентации).

## 5. Мерж и пуш

- PR `feature/debug-mode` → `feature/crystal-visual` (или сразу цепочкой в main).
- Пуш всех четырёх веток, PR из `feature/elemental-detonators` тоже висит локально.
- В прод (`npm run build`) дебаг не попадает: кнопка DEBUG обёрнута в
  `import.meta.env.DEV`, пресеты применяются только из DebugHubScene.
