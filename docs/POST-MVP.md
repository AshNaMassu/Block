# ELEMENTAL BLAST — POST-MVP BACKLOG

## Главный принцип

Сначала проверяем MVP:

```text
D1 retention
D7 retention
средняя сессия
частота комбо
частота спецфигур
first_special_received
конверсия rewarded
стабильность билда
```

Если core loop не работает, мета-системы его не спасут.

Поэтому post-MVP делим не на «всё сразу», а на волны:

```text
Patch 1.2 — retention foundation
Patch 1.3 — goals, content, leaderboards
Patch 1.4 — monetization
Patch 1.5 — liveops
Patch 2.0 — крупная мета / сезонный контент
```

## 1.1. Бестиарий / духи стихий

### Было в заметках

```text

пассивные перки к очкам
```

40 духов — это много контента, баланса и UI.

# 2. Новые идеи, которые хорошо дополнят проект

Это не было в исходных заметках, но может хорошо лечь на текущий дизайн.

---

## 2.1. Daily Seed Mode

### Суть

Каждый день все игроки получают одинаковый seed:

```text
одинаковые фигуры
одинаковая последовательность
одинаковые стихии
```

Игрок играет одну попытку или ограниченное число попыток.

Результат попадает в дневной лидерборд.

### Почему это сильно

У тебя уже заложен deterministic seed-based spawn.

Daily Seed почти бесплатно вытекает из архитектуры.

### Плюсы

```text
ежедневный возврат;
соревновательность;
честный лидерборд;
хорошо для Яндекс Игр;
можно делать без нового контента.
```

### Приоритет

```text
Patch 1.2 или 1.3
Очень рекомендую.
```

---

## 2.2. Puzzle Pack / Training Grounds

### Суть

Набор заранее собранных ситуаций:

```text
Уровень 1: замкни обычную линию
Уровень 2: замкни стихийную линию
Уровень 3: сделай комбо 2 линии
Уровень 4: используй Bomb
Уровень 5: собери Чистое Очищение
Уровень 6: сделай комбо 3 линии
```

### Зачем

Это улучшает онбординг и даёт контент.

Игрок учится не в случайной партии, а в понятной ситуации.

### Плюсы

```text
лучше D1;
лучше понимание комбо;
меньше фрустрации;
можно использовать как tutorial 2.0.
```

### Приоритет

```text
Patch 1.3
```

## 2.6. Spirit Mastery Light

### Суть

Облегчённая версия Бестиария.

4 духа:

```text

💧 Дух Воды
🌿 Дух Земли
💨 Дух Воздуха
```

Каждый качается за действия своей стихией:

```text
стихийные линии;
Чистые Очищения;
Fury этой стихии;
комбо этой стихией.
```

### Награды

Лучше делать так:

```text
уровень 1: иконка
уровень 2: титул
уровень 3: эффект линии
уровень 4: аура Fury
уровень 5: скин стихии
уровень 6: рамка профиля
уровень 7: особый звук
уровень 8: анимация Очищения
уровень 9: золотой скин
уровень 10: легендарный титул + косметический эффект
```

### Важно

Если есть лидерборды, бонусы к очкам лучше либо не давать, либо давать только в обычном режиме, не в Daily Seed.

### Приоритет

```text

```

# 5. Что я бы не делал сразу

---

## 5.1. Полный Бестиарий на 40 духов

Слишком много контента.

Сначала:

```text
4 духа
простая прокачка
косметические награды
```

Если мета зайдёт — расширять.

---

## 5.2. Sticky-баннер

Может ухудшить UX.

Добавлять только если:

```text
retention хороший;
ARPDAU слабый;
нужно быстро поднять доход.
```

---

## 5.3. Сложные IAP с преимуществом

Например:

```text
купи всех духов сразу;
получи ×1.5 перманентно;
открой Insane за деньги.
```

Это может испортить лидерборды и доверие игроков.

Лучше:

```text
IAP = косметика + удобство.
```

# 6. Как выбирать фичи по метрикам

После MVP смотреть не «что нравится», а «что болит».

---

## Если D1 низкий

```text
D1 < 30%
```

Добавлять:

```text
улучшенный онбординг;
Puzzle Pack;
первую сессию с guaranteed комбо;
подсказки;
упрощение первых партий.
```

Не добавлять:

```text
мета;
IAP;
Insane.
```

---

## Если D7 низкий

```text
D7 < 15%
```

Добавлять:

```text
Daily Challenges;
Daily Seed;
трофеи;
квесты;
streak-награды.
```

---

## Если игроки не видят спецфигуры

```text
first_special_received < 50%
specials_received_per_game < 0.3
```

Добавлять:

```text
controlled onboarding;
повысить частоту комбо;
первый guaranteed Bomb;
обучающие puzzle-ситуации.
```

---

## Если Fury слишком редкий

```text
fury_active_time / session_time < 5%
```

Добавлять:

```text
чуть больше overflow;
чуть больше стихийных линий;
награды за Очищение.
```

---

## Если Fury слишком частый

```text
fury_active_time / session_time > 40%
```

Добавлять:

```text
снизить длительность;
снизить overflow;
усложнить комбо.
```

---

## Если игроки упираются в звёздный кап

```text
много игроков с stars >= 60
```

Добавлять:

```text
косметику за звёзды;
темы;
скины;
престиж-рамки.
```

---

## Если доход слабый

```text
ARPDAU низкий
rewarded conversion низкая
```

Добавлять:

```text
Remove Ads IAP;
Starter Pack;
новые rewarded-точки;
аккуратный interstitial tuning.
```
